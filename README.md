# .github

Community-health files for the GatewayIRAN profile: issue and pull-request
templates, a code of conduct, and security-policy pointers. They apply across
the [`certway`](https://github.com/GatewayIRAN/certway) project and the rest of
the profile.

- Report a bug or a security issue: use
  [GitHub private vulnerability reporting on certway](https://github.com/GatewayIRAN/certway/security/advisories/new)
  — do **not** open a public issue for security.
- The community for releases, how-tos and comparisons is the
  [Telegram channel](https://t.me/GatewayIRAN).

These files are intentionally sparse. The only product is **certway**; everything
else here just keeps it a usable place to land.
